Entry for the [One Word From Grandma](https://make.fun/c/u-0xkianno-one-word-from-grandma-f04bed16) competition on make.fun.

## The word

**Brainbox** — the word grandma would text about AI. Her era's word for a
clever person, and a box with a brain is exactly what the machine is: warm,
a little baffled, funny in one word, and tied to the thinking machine rather
than just any gadget. It beats the obvious picks (Robit, Doohickey,
Contraption, ChatGBT) by being fresher and warmer while staying instantly
readable.

## How it works

`main.ts` (Node 22 stdlib only) writes exactly one word, `Brainbox`, to
`/output/entry.txt` — UTF-8, no trailing newline, 8 characters, inside the
1–30 character gate.

```sh
node main.ts
cat /output/entry.txt
```
